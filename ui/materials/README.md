# Acrylic noise

The acrylic noise PNG is redistributed unmodified from Microsoft UI XAML,
commit `07e0354d2e06572501ef48078a3cc91138749c9f`,
`controls/dev/Materials/Acrylic/Assets/NoiseAsset_256X256_PNG.png`.
See the [Microsoft MIT license](../icons/winui-chevron/LICENSE).

The Skia compositor tiles it in physical pixels and composites it at 2% as
described in AcrylicBrush.cpp and MaterialHelper.cpp from the same revision.
